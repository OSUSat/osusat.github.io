# OSUSat Wiki
Knowledge base website for OSUSat

A static site, styled with [Tailwind CSS](https://tailwindcss.com) + [daisyUI](https://daisyui.com)

## Structure

- `index.html`: wiki home page, links out to each doc page
- `manual/index.html`: the Contributor Manual

## Local preview

Any static file server works, e.g.:

```
python3 -m http.server -d . 8000
```

then open `http://localhost:8000`.
